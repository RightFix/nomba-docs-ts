Version history

1.0.0

Initial release of the TypeScript SDK, aligned with Nomba's published OpenAPI spec and the nomba-python SDK for full feature parity.

  • 93 endpoints from Nomba's OpenAPI spec, across 14 resource groups.
  • Auth via the accountId header and the /v1/auth/token/issue token endpoint.
  • Full Accounts surface: list/create sub accounts, parent & sub balances, suspend/reactivate, access control, and terminal assignment.
  • Virtual Accounts on /v1/accounts/virtual/*: create (parent or sub), fetch, filter, update, expire, and transactions.
  • Online Checkout covering orders, transaction management, tokenized cards, refunds, card-detail/OTP flows, flash account numbers, and the saved-card OTP flow.
  • Charge sequence on /v1/checkout/*: card details, OTP, resend, and confirm-receipt.
  • Transfers: bank-code lookup, account verification, and bank/wallet transfers from parent or sub accounts (/v2/transfers/*).
  • Terminals: assign/unassign (parent or sub account) and send a payment request to a terminal.
  • Global Collections and Global Payout (incl. payout accounts with a useSandbox flag).
  • Async/await with axios HTTP client — TypeScript is async-first, no sync/async split.
  • Typed responses via generated TypeScript interfaces.
  • Cursor pagination helpers (paginate async generator).
  • Guided card-payment OTP/3DS flow (CardPaymentFlow).
  • Webhook signature verification with replay-window protection.
  • Token-fetch locking and retry-with-backoff on 429/5xx.
  • Local nested request-body validation against the bundled spec.
  • Bounded-concurrency helper (gatherLimited) for fan-out calls.
  • OAuth2 client-credentials with automatic token caching and transparent 401 refresh.
