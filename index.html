Unofficial · community-maintained

Every Nomba endpoint, already wired.

nomba-ts is a TypeScript SDK generated directly from Nomba's own OpenAPI spec — 96 methods across 14 resource groups, async/await with axios, typed responses, and request validation built in. No endpoint URLs to memorize, no manual token handling, no guessing field names. 

npm install nomba-ts
# or
yarn add nomba-ts
# or
pnpm add nomba-ts
import { Nomba } from 'nomba-ts'

const nomba = new Nomba({
  apiKey: '...',
  apiSecret: '...',
  accountId: '...',
})

const account = await nomba.virtualAccounts.createVirtualAccount({
  accountRef: 'acct-jane',
  accountName: 'Jane Doe',
})

What's covered

96 methods Full API reference Accounts, Virtual Accounts, Checkout, Charge, Transfers, Terminals, Transactions, Airtime/Data, CableTV, Electricity, Betting, Direct Debits, Global Collections, Global Payout. Async/await Getting started Install, authenticate, handle errors, and make your first request. Cursor-based Pagination iterators Loop over every page of a list endpoint without writing the loop yourself. 3 steps Guided card payment flow Card details → OTP or 3DS → confirm, decoded into plain booleans. HMAC-SHA256 Webhook verification Signature check plus replay-window protection on the timestamp. Locked + retried Reliability built in Token-fetch locking and automatic backoff on 429/5xx responses.

Why generated, not hand-written

Every resource method, its required and optional fields, and its response shape come straight from Nomba's published OpenAPI spec — not transcribed by hand. That means field names match exactly (accountRef, not a guess at account_ref), and nested request bodies are checked locally against the same spec before anything goes over the network.

Scope

This SDK is unofficial and not affiliated with Nomba. It wraps Nomba's public API; see developer.nomba.com for the canonical reference and your dashboard credentials.
