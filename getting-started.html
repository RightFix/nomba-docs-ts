Getting started

Install, authenticate, request.

Three things you need from your Nomba dashboard: an apiKey (client ID), an apiSecret, and an accountId. The SDK handles the OAuth2 token exchange for you from there.

Install

npm install nomba-ts
# or
yarn add nomba-ts
# or
pnpm add nomba-ts

Async client

TypeScript is async-first — every resource method is an async function returning a Promise. Create one Nomba instance and reuse it; it manages its own axios connection pool and OAuth2 token cache.

import { Nomba } from 'nomba-ts'

const nomba = new Nomba({
  apiKey: '...',
  apiSecret: '...',
  accountId: '...',  // optional, but recommended
  baseUrl: 'https://api.nomba.com',  // default
  verifySsl: true,                   // set false for sandbox
})

const account = await nomba.virtualAccounts.createVirtualAccount({
  accountRef: 'acct-jane',
  accountName: 'Jane Doe',
})
console.log(account.data.accountNumber)
console.log(account.code, account.description)

ESM vs CommonJS

The package is published as ESM. For CommonJS you can use a dynamic import:

const { Nomba } = await import('nomba-ts')

Error handling

All errors inherit from NombaError. The three you'll see most:

import { NombaAPIError, NombaAuthError, NombaValidationError } from 'nomba-ts'

try {
  await nomba.virtualAccounts.fetchVirtualAccount('missing-ref')
} catch (e) {
  if (e instanceof NombaAuthError) {
    console.log('auth failed:', e.message)
  } else if (e instanceof NombaValidationError) {
    console.log('bad request, caught locally:', e.missing)
  } else if (e instanceof NombaAPIError) {
    console.log('api error:', e.statusCode, e.code, e.responseBody)
  }
}
Note

NombaValidationError is raised before any request goes out — it checks nested required fields (like everything inside a request body object) against Nomba's own spec. See request validation.

Response shape

Every method returns a typed Promise<T> generated from Nomba's response schema, mirroring Nomba's actual JSON keys (camelCase, not snake_case):

const account = await nomba.virtualAccounts.createVirtualAccount({
  accountRef: 'acct-jane',
  accountName: 'Jane Doe',
})
console.log(account.data.accountNumber)
console.log(account.code, account.description)

Creating a checkout order

The checkout order body is wrapped in an order object and takes a tokenizeCard flag:

const order = await nomba.checkout.createOnlineCheckoutOrder({
  order: {
    orderReference: 'order-001',
    customerId: 'cust-001',
    callbackUrl: 'https://example.com/cb',
    customerEmail: 'jane@example.com',
    amount: 1000,
    currency: 'NGN',
    allowedPaymentMethods: ['Card', 'Transfer'],
  },
  tokenizeCard: false,
})
console.log(order.data.checkoutLink)

Local request validation

Write calls are validated against Nomba's spec before any network request, so you catch missing fields early:

import { NombaValidationError } from 'nomba-ts'

try {
  await nomba.checkout.createOnlineCheckoutOrder({
    order: { orderReference: 'x', customerId: 'c', callbackUrl: 'https://example.com/cb', customerEmail: 'a@b.com', amount: 1000, currency: 'NGN' },
    tokenizeCard: false,
  })
} catch (e) {
  if (e instanceof NombaValidationError) {
    console.log(e.message)
    console.log(e.missing)  // ['...']
  }
}
