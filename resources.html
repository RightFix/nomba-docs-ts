API reference

96 methods, 14 ledgers.

Every method below is available on the Nomba instance under the resource group shown in each heading, e.g. nomba.virtualAccounts.createVirtualAccount(...). All methods are async and return a typed Promise. Field names and required/optional arguments are generated from Nomba's OpenAPI spec.
